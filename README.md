# Tiago Ferreira · CV

Site pessoal com o CV. React + TypeScript + Vite, bilingue PT/EN, mobile-first.

## Correr

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # build de produção em dist/
```

## Estrutura

- `src/content.ts`: todos os textos (PT e EN), projetos e links.
- `src/styles.css`: design tokens e estilos (direção "B2 · Gelo").
- `src/components/`: uma secção por componente.
